# Аналитическое хранилище для интернет-магазина

В проекте мы строим витрины для анализа заказов, продаж и покупательской активности.

Сначала данные из PostgreSQL загружаются в схему `raw` в Greenplum. Затем в `staging` поля приводятся к единому виду. В `intermediate` оплаты сводятся до уровня заказа, а для категорий товаров определяются родительская и корневая категории.

В итоге в `marts` получаем 5 витрин:

- `fct_orders` - заказы без тестовых
- `fct_order_items` - товары в заказах
- `dim_customers` - клиенты и их подтверждённые покупки
- `dim_products` - товары и их категории
- `dim_dates` - календарь заказов
